## 1. Project Overview

A granular, task-by-task roadmap for designing a 4-Switch Non-Inverting Buck-Boost Converter from scratch in LTspice, with a clear migration path to SKY130 ASIC implementation.

### 1.1 Design Specifications

| Parameter | Value |
|-----------|-------|
| Input Voltage (Vin) | 2.5V – 4.2V (Li-ion battery) |
| Output Voltage (Vout) | 3.3V (fixed) |
| Max Output Current (Iout) | 100 mA |
| Switching Frequency (Fsw) | 500 kHz |
| Topology | 4-Switch Non-Inverting Buck-Boost |
| Control Method | Purely Analog – PWM Comparator + Error Amplifier feedback |
| Target Process (Phase 2+) | SKY130 (SkyWater 130 nm) |
| Operating Modes | Buck (Vin > Vout), Boost (Vin < Vout), Buck-Boost (Vin ≈ Vout) |
| Inductor (calculated) | ≈ 47 µH |
| Output Capacitor (calculated) | ≈ 1 µF |
| Input Capacitor (calculated) | ≈ 4.7 µF |

### 1.2 Operating-Mode Summary

| Mode | Condition | Active Switches | Duty-Cycle Logic |
|------|-----------|-----------------|------------------|
| Buck | Vin > Vout + ΔV | S1+S2 switching, S3=OFF, S4=ON | D = Vout / Vin |
| Boost | Vin < Vout − ΔV | S1=ON, S2=OFF, S3+S4 switching | D = 1 − Vin/Vout |
| Buck-Boost | Vin ≈ Vout (±200 mV) | All 4 switches switching | Blended / overlap mode |

## 2. Hand Calculations (Power Stage Sizing)

### 2.1 Duty Cycle

| Condition | Vin (V) | Formula | D |
|-----------|---------|---------|---|
| Buck – max Vin | 4.2 | D = Vout / Vin | ≈ 0.786 |
| Buck – min Vin | 3.3 + ε | D = Vout / Vin | ≈ 1.0 (boundary) |
| Boost – max Vin | 3.3 − ε | D = 1 − Vin/Vout | ≈ 0 (boundary) |
| Boost – min Vin | 2.5 | D = 1 − Vin/Vout | ≈ 0.242 |

### 2.2 Inductor

- Target ripple ΔIL = 30% × Iload = 30 mA (worst case at Vin = 4.2V)
- `L = Vout × (1 − D) / (Fsw × ΔIL) = 3.3 × 0.214 / (500k × 0.03) ≈ 47 µH`

### 2.3 Output Capacitor

- Target output ripple ΔVout ≤ 10 mV
- `Cout = ΔIL / (8 × Fsw × ΔVout) = 0.03 / (8 × 500k × 0.01) ≈ 750 nF → use 1 µF`

### 2.4 Input Capacitor

- `Cin ≈ D(1−D) × Iload / (Fsw × ΔVin) ≈ 4.7 µF` (ΔVin = 50 mV target)

### 2.5 Feedback Resistor Divider

- Vref = 1.2V, Vout = 3.3V
- `R1/R2 = (Vout − Vref) / Vref = (3.3 − 1.2) / 1.2 = 1.75 → R1 = 175 kΩ, R2 = 100 kΩ`

### 2.6 Type-II Compensator Zero & Pole

- `fz = 1 / (2π × R1 × Cf)` — place at LC resonance / 5
- `fp = 1 / (2π × R1 × (Cf ‖ Cp))` — place near Fsw / 2
- `f0 = 1 / (2π × √(L × Cout)) = 1 / (2π × √(47µ × 1µ)) ≈ 23.2 kHz`

## 5. Interview Talking Points

| Question | Key Answer Points |
|----------|------------------|
| Why a 4-switch non-inverting topology? | Single inductor handles both step-up and step-down. Non-inverting output avoids polarity inversion. Used in Li-ion PMIC designs (e.g. Qualcomm PM8150). |
| How do you choose switching frequency? | 500 kHz balances inductor size (smaller at higher Fsw) vs switching losses (increase with Fsw). At 500 kHz, L = 47 µH — physically small but feasible. |
| Why Type-II compensator? | Buck-Boost plant has a double LC pole (~23 kHz) requiring a compensator zero to boost phase. Type-II adds one zero and one HF pole — sufficient for this topology. |
| How do you handle mode transitions? | Hysteresis comparator monitors Vin. Buck mode when Vin > 3.5V, Boost when Vin < 3.1V, overlap (all 4 switching) in 3.1–3.5V window. |
| What limits efficiency in this design? | Conduction loss: Irms² × Rds(on). Switching loss: ½ × Vds × Id × (tr+tf) × Fsw. Gate charge loss: Qg × Vgs × Fsw. Inductor DCR loss: IL² × DCR. |
| Why is phase margin important? | PM < 45° → underdamped closed-loop → Vout oscillations on transients. PM = 0° → instability. Target 45–70° for PMIC applications. |
| How does the error amplifier connect to the Buck-Boost? | Error amp senses Vfb = Vout × R2/(R1+R2), compares to Vref = 1.2V, outputs Verror. Verror compared to Vramp by PWM comparator → duty cycle control. |
| What is the significance of RHP zero in Boost mode? | Boost converter has a RHP zero at `fRHP = (1−D)²×Rl / (2π×L)`. It limits achievable crossover frequency. Must set fc < fRHP/3 for stable loop. |
